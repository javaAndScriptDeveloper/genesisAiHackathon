# frontend-quality

Read AGENTS.md, then docs/agent/styling.md, docs/agent/ux-rules.md and docs/agent/ui-kit.md. Reuse components from `@/components/ui`; follow tokens, corners mixins, breakpoints. Every data view has skeleton, empty and error states. Before saying done: `bun run typecheck`, `bun run test`, open the page (desktop and 360px) and check keyboard focus.

Always start from [AGENTS.md](../../../AGENTS.md).
