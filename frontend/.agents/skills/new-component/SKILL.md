# new-component

Follow docs/agent/ui-kit.md 'Adding a component'. PascalCase folder with Name.tsx + Name.module.scss; tokens only; `corners.radius`; hit targets >= 4.4rem; Hugeicons via `Icon` (docs/agent/icons.md); export from components/ui/index.ts; add an example to components/sections/UiKitShowcase; run `bun run typecheck` and view /ui-kit.

Always start from [AGENTS.md](../../../AGENTS.md).
